# PR05 关单推迟与行动预警

基于 PR03 的活动及完成时间合同，计划编号 PR05，非 GitHub 编号。

预计 PO 日期从一个季度推迟到更晚季度时，以 `CRM Opportunity History` 的 `po_date` 行作为预警身份，包括 Q4 到次年 Q1。同季度调整不新建实例；再次跨季度推迟使用新的历史行，旧处理历史保留。恢复到该次推迟前的季度、商机收到 PO 或关闭后清除当前提醒。只显示当前仍有效且在所选截止日前已经发生的实例，当前负责人决定处理归属。缺审计覆盖时显示数据不足，历史日期不猜测。

经理保存下一步不会清除预警。记录实际行动和未来复核日期后，实例暂移至已处理列表；复核日到来且仍有效时恢复提醒。新延期不继承旧实例的处理。每日通知复用现有来源权限与去重，发给经理和有商机读取权的当前销售负责人；历史首次上线超过通知窗口的旧延期不刷屏。

行动状态保留存储值 Open（界面显示未开始）和 Done，增加 In Progress、Blocked、Rescheduled。所有未完成状态继续进入计划、逾期、下一步及原有提醒；只有 Done 写入完成时间，重开清除完成时间。改期是显式状态，期限独立维护，两者均写现有行动审计；不推断实际完成。历史 Open 保持未完成，不回填开始时间。

S6 未收到 PO 的无配置默认阈值改为原 SPEC 的 56 天，已有经理设置和站点配置继续优先。降档仍按页面所选期间展示，保留现有说明；系统无可核实的“上次 review”会话时间，本项不发明该时间，也不改变降档既有合同。

验证覆盖跨年/同季度/回退/再次延期、处理复核日和 CAS、通知去重与权限、所有行动消费者及完成周期、默认配置优先级。完整门禁和双审结果待实施完成后记录。
