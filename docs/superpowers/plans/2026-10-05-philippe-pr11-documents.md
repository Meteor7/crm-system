# PR11 商机资料与评分卡入口

基于 bce349872e063e29b6717f7c1a4483d1d58f582f，分支 codex/philippe-11-documents。本项可独立审查，不包含 PR01、PR03 的实现。

每个商机自动具有固定的 `/opportunities/:opportunityId/documents` 页面，聚合明确关联该商机的 Status 附件、Demo 表单及报告、RFQ、报价和拜访记录。没有手动创建目录的步骤，不复制附件、不改变原始业务文件。资料及下载沿用各来源的范围和受控入口，用户看不到的来源不计入列表。资料入口与商机内的 Blue Sheet 互相直达。

Product/Deal scorecard 使用两个可空的外部链接字段；只接受绝对 HTTP/HTTPS 地址，不读取远端内容。销售及经理依照现有商机范围编辑，保存携带商机版本，部分更新保留未提交的另一链接，更改进入商机历史。无效旧值不生成可点击链接；缺失链接、空来源列表及下载时已删除的文件均有提示。远端链接失效或外部服务权限由打开后的服务反馈，本功能不验证外部网站内容。

这是 CRM 内逻辑资料目录；没有建立外部网盘物理文件夹，评分卡没有评分引擎。原 SPEC 的外部物理目录若为硬性要求，应另行确认连接服务及权限，不能以本实现宣称完成外部存储集成。

已有针对性检查：TypeScript 通过，三项资料页交互测试通过，两项链接规则测试通过。适配器与国际化检查首轮通过；补充适配器参数用例后待再验证。真实 Frappe 用例覆盖链接版本冲突、修改历史、部分清空、无文件复制、越权拒绝及关联拜访的独立范围。真实后端、完整门禁、两位审查者与远端审查尚待完成。
