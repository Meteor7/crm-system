# 桌面侧栏折叠设计

## 目标

桌面端侧栏默认展开。用户点击侧栏顶部的收起按钮后，侧栏整体向左移出屏幕，主内容区扩展到全宽；顶部栏显示展开按钮。刷新页面后恢复默认展开，不持久化状态。

## 交互

- 展开状态：品牌区右侧显示“收起导航”按钮。
- 收起状态：侧栏完全隐藏，顶部栏左侧显示“展开导航”按钮。
- 切换使用短距离平滑过渡，不改变当前路由和权限过滤。
- 移动端继续使用现有抽屉导航，本次不调整。
- 按钮提供 `aria-label`、`aria-expanded` 和稳定测试标记。

## 视觉层级

- 导航分组标题（管理中心、Sales 模块、Demo 与验证、设备与知识）：`12px`、`800` 字重。
- 功能栏目：`10px`、`600` 字重。
- 保持现有颜色、图标、激活态和间距体系，仅加强分组与栏目层级。

## 实现范围

- `src/app/AppShell.vue`：增加桌面折叠状态、控制按钮和布局状态类。
- `src/app/AppShell.test.ts`：覆盖桌面收起、展开、内容区扩展和语义标记。

## 验收

- 默认侧栏展开。
- 点击后侧栏完全向左隐藏，主内容占满可用宽度。
- 顶部展开按钮能够恢复侧栏。
- 页面刷新后默认展开。
- 导航分组标题明显大于功能栏目。
- 现有移动端抽屉测试继续通过。
