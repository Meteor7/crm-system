# 新建表单必填红星设计

## 目标

所有可用的“新建”表单中，凡是现有校验定义为必填的字段，都在字段名称旁显示红色 `*`。

## 范围

- 覆盖当前系统中可操作的新建客户、联系人、关键人、拜访、Demo Request、Opportunity、Booking、Action 和 Wafer Test Run 等表单。
- 以现有 `required` 属性及已有提交校验为必填依据，不新增或删除必填规则。
- 新建/编辑共用表单时，仅在新建状态显示红星；编辑及其他流程状态不扩大视觉变更。
- 动态必填字段只在当前条件使其必填时显示红星。

## 实现

- 在现有字段标签文字旁显式渲染统一的 `.required-mark` 元素，内容为 `*`。
- 标记使用系统危险色变量，保留轻微间距，不改变表单网格、字段宽度或输入控件结构。
- 标记设为装饰性内容，避免屏幕阅读器重复朗读；输入控件原有 `required` 属性继续承担语义。
- 不引入新依赖，不重构现有表单组件，不修改 API、数据模型或业务流程。

## 验收标准

1. 每个新建表单的全部必填字段名称旁都有红色 `*`。
2. 非必填字段不显示红色 `*`。
3. 新建/编辑共用组件只在新建状态显示红星。
4. 原有必填校验、提交结果和表单布局保持不变。
5. 针对性组件测试、类型检查和生产构建通过。
