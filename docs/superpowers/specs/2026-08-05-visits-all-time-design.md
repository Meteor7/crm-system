# 拜访列表全时间范围设计

## 目标

拜访管理页不再限制默认日期区间，始终查询并展示当前账号权限范围内的全部拜访记录。

## 范围

- 删除拜访页的开始日期和结束日期控件。
- `listVisits` 请求不再发送 `dateFrom`、`dateTo`。
- 重置筛选时只重置搜索、客户、状态和负责人。
- 新建拜访后直接重新加载列表，不再扩展日期区间。
- 保留搜索、客户、状态和负责人筛选。
- 不增加归档功能，不修改拜访状态、数据库结构或后端日期筛选能力。

## 数据流

页面加载或其他筛选变化时，前端仅发送搜索、客户、状态、负责人和联系人参数。后端现有 `list_visits` 在未收到日期参数时返回权限范围内的全部匹配记录。

## 验收标准

1. 页面不显示开始/结束日期输入框。
2. 初次加载、重置筛选及新建拜访后均不发送日期范围参数。
3. 不同月份的拜访可同时出现在列表中。
4. 现有客户、状态、负责人、搜索及权限过滤保持有效。
5. 前端类型检查、生产构建和拜访聚焦测试通过。
