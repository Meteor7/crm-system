# Boss 首页多排订阅看板设计

## 目标

将 Boss 首页现有的一排三张订阅看板扩展为可增加多排。每排固定包含三张看板，用户在“管理订阅”弹窗中增加、配置或删除订阅排；首页按每排三张连续展示，不显示自定义组名。

## 已确认范围

- 仅对 `Management Viewer` 的首页经营看板生效。
- 默认保留一排，内容沿用当前三个默认订阅。
- 每排必须恰好选择三张看板。
- 第一排不可删除，后续新增排可以整排删除。
- 不提供自定义组名；管理界面只用“第 1 排、第 2 排……”表示位置。
- 同一张看板不能同时出现在不同排。
- 当前共有 18 张看板，因此最多六排。
- 设置继续保存在当前浏览器，并按用户 ID 隔离。
- 非 Boss 角色、KPI、数据口径、团队日程和相关事项保持不变。
- 不增加后端接口、依赖、拖拽排序或跨设备同步。

## 方案比较

### 方案 A：选中一排，共用看板目录（采用）

弹窗顶部显示所有订阅排和“增加一排”按钮。用户先选中要编辑的排，再从下方统一目录选择三张看板。已被其他排使用的看板显示所在排并禁止重复选择。

优点是目录只出现一次，弹窗长度可控，用户能清楚知道正在编辑哪一排。

### 方案 B：每排重复完整看板目录

每个订阅排下方都显示 18 张看板。操作直观，但两排后内容就过长，重复信息很多，不采用。

### 方案 C：新增排分步向导

点击新增后进入单独步骤选择三张，再返回总览。状态边界清楚，但更换已有排需要更多点击，不采用。

## 首页展示

订阅区标题保留“我的订阅看板”，管理按钮显示当前总数，例如“管理订阅 · 6 张”。

每个订阅排渲染为独立的三列网格：

- 桌面端一排三张。
- 窄屏沿用现有响应式规则，三张纵向排列。
- 首页不显示“第几排”或组名，只通过行间距区分。
- 所有排中的订阅看板都从“展开全部”中过滤，任何看板只出现一次。

## 管理订阅交互

弹窗顶部为订阅排控制区：

1. 默认选中第一排。
2. 每个排按钮显示“第 N 排”和完成度 `0/3` 到 `3/3`。
3. “增加一排”只在剩余未订阅看板至少还有三张时可用。
4. 新增后创建空排并立即选中。
5. 第一排不显示删除操作；其他排提供“删除此排”。
6. 删除排只修改弹窗草稿，点击保存后才影响首页。
7. 关闭或取消弹窗时，所有新增、删除和选择操作都被丢弃。

下方继续按“经营核心、客户分析、流程与执行”显示统一看板目录：

- 点击当前排已选看板会取消选择。
- 当前排不足三张时可以选择未被其他排使用的看板。
- 当前排已有三张时，其他未选看板禁用，需先取消一张再替换。
- 已被其他排使用的看板禁用，并标注“第 N 排已订阅”。
- 保存按钮仅在至少有一排、每排恰好三张、全部 ID 唯一时可用。

## 数据结构和迁移

页面状态从单个 ID 数组升级为二维数组：

```ts
type DashboardSubscriptionGroups = DashboardChartId[][]
```

有效持久化数据必须满足：

- 外层数组包含一至六排。
- 每排恰好三个已知看板 ID。
- 所有排中的 ID 全局唯一。

新存储键使用版本 `v2`：

```text
semiconductor-crm:boss-dashboard-subscriptions:v2:<user-id>
```

读取顺序：

1. 尝试读取并校验 `v2` 数据。
2. 如果不存在 `v2`，读取旧版 `v1` 三项数组并包装为第一排。
3. 如果数据损坏、包含未知 ID、排数或每排数量错误、存在重复 ID，则回退到默认第一排。

保存只写 `v2`。旧 `v1` 数据不删除，避免执行破坏性存储操作。

如果浏览器存储不可用，当前页面仍应用已保存的草稿，并显示“本次页面选择仍然有效”的提示。

## 代码边界

- `dashboard-subscriptions.ts` 负责二维订阅数据的校验、默认值、`v1` 迁移和 `v2` 读写。
- `DashboardPage.vue` 负责草稿排、当前编辑排、目录禁用状态、首页多排渲染和展开区去重。
- `ModalShell.vue` 继续使用现有禁用提交能力，不增加新的通用组件行为。
- 不修改图表目录、聚合口径、权限模型或 API。

## 测试与验收

1. 无本地设置时首页显示一排三个默认看板。
2. 旧版 `v1` 三项数组自动恢复为第一排。
3. 点击“增加一排”后出现空的第二排并自动进入编辑状态。
4. 第二排选满三张前无法保存，选满后可以保存。
5. 第一排已订阅的看板在第二排不可选择，并显示占用位置。
6. 保存后首页出现两排共六张，顺序与草稿一致。
7. 六张订阅看板均不在“展开全部”中重复出现。
8. 重新挂载页面后从 `v2` 恢复所有排。
9. 删除第二排并保存后，首页恢复一排，被删除的三张回到“展开全部”。
10. 第一排不可删除；未使用看板不足三张时不能继续增加排。
11. 取消弹窗不会保存新增、删除或替换操作。
12. 损坏、重复或过期数据回退到默认第一排。
13. 非 Boss 用户看不到订阅入口。
14. 聚焦单元测试、TypeScript 类型检查和生产构建通过。
15. 浏览器验证桌面和窄屏下的增加、选择、保存、刷新恢复、删除和无重复展示。
