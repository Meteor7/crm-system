# Calendar 详情跳转设计

## 目标

在 Calendar 中点击任一安排卡片后，在右侧详细资料下方显示一个普通的“查看详情”按钮。按钮沿用项目现有按钮风格，不增加弹窗、菜单、特殊动画或额外视觉组件。

## 跳转规则

- Sales 拜访：进入拜访模块并通过 `focus` 查询参数定位对应拜访记录。
- Demo Request：进入该 Demo Request 的详情页。
- Demo Test：进入验证模块并通过现有 `focus` 查询参数定位对应 Evaluation。
- Booking：进入该 Booking 的详情页。

普通卡片详情和“当天全部安排”中的选中项目详情使用同一套跳转规则和同一个按钮文案。

## 数据与交互

Calendar 事件保存上游记录 ID，并据事件类型生成 Vue Router 路由对象。用户点击“查看详情”后进行站内跳转，不打开新窗口。

拜访模块补充读取 `focus` 参数：目标存在时突出对应表格行；目标不存在时保持演示员工152列表，不报错、不自动打开编辑表单。

## 测试与验收

- 四类 Calendar 事件均生成指向具体记录的正确链接。
- 切换选中卡片后，按钮目标同步变化。
- 普通详情和当天安排详情都显示按钮。
- 拜访页面能够根据 `focus` 定位并突出对应行。
- 目标记录已不存在时，目标模块仍能演示员工152加载。
- 聚焦测试、前端全量测试、类型检查和生产构建通过。

## 非目标

不重构信息中心，不新增通用路由抽象，不改变现有 Calendar 卡片、筛选器或详情布局。
