# 项目周期看板客户筛选设计

## 目标

在项目周期看板工具栏增加客户下拉筛选框，使用户能够同时筛选 Demo Request、Demo Test 和过去 100 天已完成项目。

## 交互

- 下拉框标签为“客户”，默认值为“全部客户”。
- 客户选项从当前权限范围内的 Demo 项目 `account` 字段自动去重，并按名称排序。
- 客户条件与搜索、健康状态、Sales 和 Engineer 条件叠加。
- 无匹配项目时，各栏目继续显示“当前筛选下暂无项目”。
- 筛选结果不改变栏目结构、DDL、颜色、加急规则或档案详情入口。

## 状态与路由

- `DemoWorkflowPage.vue` 持有 `customer` 状态。
- 非默认值写入 URL 查询参数 `customer`。
- 切换视图、打开详情和返回项目周期看板时保留该参数。
- 项目周期看板以 `customer` prop 接收当前值，并通过 `update:customer` 通知页面。

## 范围

- 仅修改 Vue/Mock 前端。
- 不修改 Frappe、API 合约、Mock 数据、权限或其他 Demo 视图。
- 不新增依赖。

## 验收

1. 项目周期看板出现客户下拉框和“全部客户”选项。
2. 选择“示例企业014有限公司”后，只显示该客户的项目。
3. URL 包含编码后的 `customer` 查询参数。
4. 切换回“全部客户”后恢复全部项目并移除该参数。
5. 现有项目周期测试和生产构建通过。
