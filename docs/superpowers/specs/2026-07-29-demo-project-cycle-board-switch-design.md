# Demo 档案项目周期看板切换设计

## 目标

在 Demo 档案页面现有视图切换控件中增加“项目周期看板”，为后续正式看板预留稳定入口。

## 视图顺序

顶部切换按钮固定为：

1. 项目周期看板
2. 生命周期看板
3. Demo 档案

## 当前行为

- “项目周期看板”使用独立视图状态 `project`。
- 点击后更新当前路由为 `/demo-workflow?surface=project`。
- 浏览器刷新后仍保留项目周期看板选中状态。
- 正式看板尚未建设时，页面显示明确的建设中空状态，不复用生命周期数据。
- “生命周期看板”和“Demo 档案”的现有内容、筛选条件、详情跳转及 URL 行为保持不变。

## 实现边界

- 扩展 `DemoSurface` 类型和路由查询解析。
- 将现有两列分段控件扩展为三列，并把“项目周期看板”放在首位。
- 增加项目周期看板空状态。
- 不新增 API、数据模型或第三方依赖。
- 不修改 Demo Request、Demo Test 或联系人模块。

## 验收标准

- 页面显示三个切换按钮，顺序与设计一致。
- 点击“项目周期看板”后按钮呈选中态，URL 包含 `surface=project`。
- 项目周期视图显示独立空状态。
- 点击另外两个按钮后仍显示原有对应内容。
- 页面测试覆盖按钮顺序、项目视图切换及 URL 状态。
