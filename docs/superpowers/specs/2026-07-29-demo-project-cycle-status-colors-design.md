# Demo 项目周期状态颜色与归档排序设计

## 目标

让项目周期看板的三类项目具备一致、可辨识的状态颜色，并将完成档案限定为过去 100 天内、按完成时间倒序展示。

## 展示规则

- Demo Request 与 Demo Test 的演示员工152项目使用 CRM 系统橙色风格。
- 客户预期剩余天数小于等于 7 天的进行中项目使用红色紧急风格。
- 当前栏目选中紧急项目时，栏目边框、标题区域、档案详情按钮和时间链同步切换为红色。
- 完成档案使用绿色风格，不参与红色紧急判断。
- 第三栏文案为“过去100天已完成 Demo”，顶部统计文案为“过去100天已完成”。

## 数据范围与排序

- 完成日期优先使用项目时间链的 Customer Review 日期，其次使用最后一次已完成 Test Run 日期，再其次使用最后一个 Artifact 创建日期。
- 仅展示完成日期距上海当天 0 至 100 天的档案，包含第 100 天。
- 完成档案按完成日期从新到旧排列。
- 进行中的 Demo Request 与 Demo Test 保持现有数据顺序。

## 边界

- 继续复用现有 `listDemoWorkflows()` 数据，不新增种子案例。
- 不修改生命周期看板、档案详情路由或 Frappe 后端。
- 不新增依赖。
