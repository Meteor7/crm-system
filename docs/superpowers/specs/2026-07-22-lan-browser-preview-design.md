# 局域网浏览器预览设计

**日期：** 2026-07-22
**范围：** 同一局域网内的浏览器访问与测试，不包含源代码协同编辑或公网发布。

## 目标

在保留现有仅限本机访问命令的同时，提供显式的局域网启动命令。同事可通过本机局域网地址访问开发版或生产预览版网站。

## 方案

- 保留 `pnpm dev`，继续监听 `127.0.0.1:5173`。
- 保留 `pnpm preview`，继续监听 `127.0.0.1:4173`。
- 新增 `pnpm dev:lan`，监听 `0.0.0.0:5173`，用于开发和热更新测试。
- 新增 `pnpm preview:lan`，监听 `0.0.0.0:4173`，用于生产构建预览。
- 当前主机局域网地址为 `203.0.113.10`；同事分别访问 `http://203.0.113.10:5173` 或 `http://203.0.113.10:4173`。

## 安全边界

- 只用于可信的公司或家庭局域网，不配置公网端口转发。
- Windows 防火墙如需授权，只允许“专用网络”，不允许“公用网络”。
- 不在命令、配置或页面中暴露密码、Token 或其他凭据。
- 当前 `.env.local` 使用 Mock Adapter。浏览器访问可用于界面测试，但不提供可靠的多用户共享业务数据。

## 失败处理

- 如果同事无法访问，依次检查两台电脑是否在同一网段、服务是否监听 `0.0.0.0`、Windows 网络类型是否为专用、端口是否被防火墙阻止。
- 不在未确认原因前永久关闭 Windows 防火墙。
- 如果本机 IP 地址变化，使用 `ipconfig` 获取新的以太网或 WLAN IPv4 地址。

## 验收标准

1. `pnpm dev:lan` 或 `pnpm preview:lan` 能演示员工152启动。
2. 本机可通过 `127.0.0.1` 和 `203.0.113.10` 访问页面。
3. 服务监听地址为 `0.0.0.0`，而不是仅监听 `127.0.0.1`。
4. 同一局域网中的另一台电脑能打开页面和静态资源。
5. 原有 `pnpm dev` 与 `pnpm preview` 行为保持不变。
