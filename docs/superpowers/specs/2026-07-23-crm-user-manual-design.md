# CRM 用户操作手册设计

**日期：** 2026-07-23  
**状态：** 已确认  
**适用系统：** Semiconductor CRM 局域网演示版

## 1. 目标

编写一份面向业务用户的全角色操作手册，覆盖 Boss、Sales Manager、Sales、FAE / 应用工程师、设备工程师和 CRM Administrator。手册以当前可见页面、权限代码和 Mock 业务闭环为准，不把尚未验证的 Frappe 后端能力描述为已上线功能。

## 2. 内容结构

手册采用“统一模块说明 + 角色任务指引”的结构，避免为每个角色重复整页功能说明：

1. 系统说明、访问方式和版本边界。
2. 角色权限矩阵。
3. 核心业务闭环。
4. 通用界面操作。
5. 十个导航模块的详细操作。
6. 各角色日常任务清单。
7. 状态与指标口径。
8. 常见问题和当前版本限制。

## 3. 单模块写作模板

每个模块统一包含：

- 功能目的；
- 适用角色；
- 操作入口；
- 操作步骤；
- 操作结果；
- 权限与注意事项。

## 4. 权限口径

- Boss 对应 `Management Viewer`，范围为跨团队只读，但可执行 Demo Request 最终审批和 External Report 发布。
- Sales Manager 管理本团队客户、商机、Booking、拜访与 Demo Request，并可审核拜访。
- Sales User 管理本人业务记录，不执行经理审核。
- FAE 与设备工程师按分配范围查看业务信息，执行工程评估、Demo Test 和服务相关工作。
- CRM Administrator 仅作为当前 Demo 的全权限测试身份，页面明确提示生产环境不存在该身份。

## 5. 版本边界

- 当前 `.env.local` 使用 `VITE_API_ADAPTER=mock`。
- `http://203.0.113.10:4173/` 是局域网生产构建预览地址，不等同于正式生产系统。
- 当前角色切换、数据权限和部分受控下载属于 Demo 演示能力。
- 正式登录、共享数据库、后端权限、审计和受控文件输出必须在 Frappe 部署后重新验收。
- Installed Tools 当前以查看为主，不描述尚不存在的新增、编辑和完整服务工单闭环。
