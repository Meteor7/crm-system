# Installed Tool 三视图设计

## 目标

将 Installed Tool 页面改造成与 Demo 档案一致的三视图工作区，避免生命周期看板、设备列表和详细档案纵向堆叠。页面默认打开生命周期看板。

本次只调整前端信息架构和交互，不修改后端接口、权限规则或 Installed Tool 数据结构。

## 三个视图

### 生命周期看板

- 页面默认视图。
- 保留现有 FAT、Shipment、Installation、SAT、Warranty 五列看板。
- 每张设备卡继续显示客户、型号、序列号、工程师和完成进度。
- 点击卡片后选择该设备并切换到设备档案视图。

### 项目周期看板

- 视觉和交互参考 Demo 档案的项目周期看板。
- 一台 Installed Tool 占一行。
- 固定信息列展示设备、客户、负责工程师和关键日期。
- 横向时间轴展示 FAT、Shipment、Installation、SAT、Warranty 五个节点，区分已完成、当前和等待状态。
- 点击设备行后选择该设备并切换到设备档案视图。

### 设备档案

- 使用当前 Installed Tool 页面下半部分的结构。
- 左侧保留设备列表，用于在档案之间切换。
- 右侧保留设备摘要和三个内部页签：交付生命周期、版本配置、质保服务。
- 编辑入口、权限判断、附件提示、状态和服务记录行为保持不变。

## 页面交互

- 页面标题区域右侧增加与 Demo 档案相同样式的三个切换按钮：项目周期看板、生命周期看板、设备档案。
- 默认选中生命周期看板。
- 三个主视图互斥渲染；筛选区、看板和设备档案不再全部同时堆叠。
- URL 查询参数保存主视图和选中设备，例如 `surface=lifecycle|project|detail` 与 `tool=<id>`。
- 无效视图参数回退到生命周期看板；无效设备 ID 回退到当前筛选结果的第一台设备。
- 在设备档案中切换设备时同步更新 URL；刷新页面后恢复当前视图和设备。

## 组件边界

- `InstalledToolsPage.vue` 负责加载数据、筛选状态、主视图路由状态和选中设备。
- 继续使用 `InstalledToolPipelineBoard.vue` 渲染生命周期看板。
- 新增 `InstalledToolProjectCycleBoard.vue` 渲染逐设备时间轴视图。
- 从现有页面抽取 `InstalledToolArchiveView.vue`，承载左侧列表和右侧详细档案，避免页面继续膨胀。
- Demo 工作流组件保持不变；只复用其视觉模式和交互约定，不引入跨业务的过度通用抽象。

## 数据与状态

- 三个视图共享同一份 `listInstalledTools` 结果。
- 现有搜索、客户、状态和工程师筛选继续生效，并同时作用于两个看板和档案列表。
- 新项目周期看板直接使用 `InstalledToolDto.milestones`，不新增前端伪造阶段数据。
- 当前详情中的本地档案补充数据和 fallback 规则保持不变。

## 空状态与错误处理

- 加载失败、无 Installed Tool、筛选后无结果继续使用现有页面状态样式。
- 两个看板分别显示清晰的空阶段或无匹配设备提示。
- 设备档案在无匹配设备时显示空状态，不渲染残留的旧设备详情。

## 验证

- 单元测试覆盖默认打开生命周期看板。
- 测试三个按钮互斥切换对应视图。
- 测试点击生命周期卡片和项目周期行会打开正确设备档案。
- 测试 URL 查询参数恢复视图和选中设备。
- 测试项目周期节点顺序和状态映射。
- 保留 Installed Tool 编辑、权限和现有详情行为测试。
- 运行类型检查、聚焦测试、Frappe 构建和浏览器桌面交互验证。

## 非目标

- 不新增 Installed Tool 阶段、字段或后端接口。
- 不修改 Demo 档案页面。
- 不重做 Installed Tool 的颜色、字体或全局设计系统。
- 不改变工程师权限和设备编辑规则。
