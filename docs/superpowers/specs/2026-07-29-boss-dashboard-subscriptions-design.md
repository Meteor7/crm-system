# Boss 首页可视化看板订阅设计

## 目标

将 Boss 首页当前固定展示的三张可视化卡片改为三个订阅位。Boss 可以从首页全部可视化看板中选择三张最关注的内容置顶；未订阅的图表继续保留在下方“展开全部”区域。

## 已确认范围

- 仅对 `Management Viewer` 的首页经营看板生效。
- 顶部 KPI、数据口径说明、团队日程和相关事项速览保持不变。
- 固定显示三个订阅位，不支持增加、减少或拖拽排序。
- 首次进入默认订阅：
  1. Demo / Wafer Test 状态
  2. 实际 Booking 月度分布
  3. 重点客户金额贡献
- 订阅设置保存在当前浏览器，不调用 Mock 或 Frappe 后端。
- 未订阅图表留在“展开全部”中；同一张图不在上下区域重复出现。
- Sales、FAE、设备工程师等非管理角色仍只看到原有个人提醒中心。

## 方案比较

### 方案 A：三个置顶订阅位（采用）

保留当前三列结构，用一个订阅管理弹窗替换三张卡片的内容。优点是页面结构稳定、Boss 操作直接、改动范围小。

### 方案 B：所有图表自由排序

支持任意数量和拖拽排序，但需要额外状态、排序交互和响应式规则，超出当前需求。

### 方案 C：独立订阅页面

配置能力更强，但 Boss 需要离开首页，且为三个订阅位新增路由和页面不划算。

## 交互设计

在三张置顶图表上方增加“我的订阅看板”标题和“管理订阅”按钮。按钮打开弹窗，弹窗按以下分类列出全部图表：

- 经营核心
- 客户分析
- 流程与执行

每个条目显示名称、简要说明和当前选择状态。Boss 可以在弹窗中调整选择：

- 最多选择三张。
- 只有恰好选择三张时才能保存。
- 取消关闭弹窗时不改变当前订阅。
- 保存后立即刷新三个订阅位，并将被替换的图表移入“展开全部”。

“展开全部”只渲染当前未订阅的图表，并沿用原有分类、空状态和数据来源。

## 数据与持久化

页面维护统一的可视化看板目录，每项包含稳定 ID、分类、标题、说明、图表配置、无数据标题和无障碍标签。订阅区和“展开全部”都从该目录筛选渲染，避免维护两套图表定义。

本地存储键包含版本号和当前用户 ID：

```text
semiconductor-crm:boss-dashboard-subscriptions:v1:<user-id>
```

读取时对内容进行校验和去重。出现以下情况时回退到默认三张：

- JSON 损坏；
- ID 已失效；
- 数量不是三个；
- 当前浏览器不支持或拒绝本地存储。

保存失败时保留当前页面选择，并提示“仅本次浏览有效”，不影响 Dashboard 数据加载。

## 权限和边界

- 入口只在 `Management Viewer` 经营看板出现。
- 订阅仅改变展示优先级，不改变数据权限、聚合口径或后端查询。
- `CRM Administrator` 现有首页行为不扩大；本功能不将演示员工170自动视为 Boss。
- 订阅设置是浏览器级 Demo 能力，不宣称账号同步或正式后端持久化。

## 测试与验收

1. Boss 首次进入时，三个默认图表按现有顺序展示。
2. 打开订阅弹窗后能看到完整图表目录和三个已选项。
3. 未选满三个或尝试超过三个时不能保存。
4. 保存新组合后，置顶区域只显示新选择的三张。
5. 被取消订阅的图表回到“展开全部”，已订阅图表不在下方重复。
6. 页面重新挂载后，从当前浏览器恢复订阅。
7. 损坏或过期的本地数据安全回退到默认组合。
8. 非 Boss 角色看不到订阅入口，个人提醒中心保持不变。
9. Dashboard 错误、拒绝、空数据和 stale 状态保持原有行为。
10. 聚焦单元测试、TypeScript 类型检查和生产构建通过。
