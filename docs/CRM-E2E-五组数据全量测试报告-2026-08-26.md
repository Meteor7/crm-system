## 14. Mock 页面与真实 staging 登录的纠正

客户端直连 `203.0.113.58:4174` 时 TCP 不通，但 staging 主机已确认监听 `0.0.0.0:4174`，Docker 前端映射为 `0.0.0.0:4174 -> 8080`，服务器本机 `/crm` 返回 301。为完成真实浏览器验收，已建立临时 SSH 回环隧道 `127.0.0.1:44174 -> 203.0.113.58:4174`；通过 `http://127.0.0.1:44174/crm` 可进入 Frappe 原生登录页。此前静态资源页看到的“演示员工24 / 销售经理”来自 Mock/未认证 fallback，不计入 staging 权限证据。后续应在隧道登录页输入真实 staging 账号，再执行 Sales/Engineer UI 验收；正式环境建议由网络演示员工170放行入站 TCP 4174 或提供受控 HTTPS 反向代理。
