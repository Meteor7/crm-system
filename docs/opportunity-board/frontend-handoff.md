## 页面与操作

路由：`/opportunity-board`（Frappe 模式为 `#/opportunity-board`）。

Review、Plan 和现有 Opportunities 列表均增加入口。保留原有商机列表。

1. 选择区域、销售、设备、市场范围，可搜索及多选。
2. 使用快捷查询，或添加条件并选择 AND / OR；输入稳定 300 ms 后查询。
3. 列表、总额、概率档位汇总和超过 21 天提醒使用同一次后端结果。
4. 支持排序、分页、显示列、六个字段分组。原币金额仅显示；人民币金额可排序。
5. 保存个人查询，恢复筛选、排序、分组和列；支持更新、重命名、删除。
6. 按当前条件和列导出全部结果；分组时每组一个 Excel 工作表。

Manager / Sales / Engineer 按后端 deal:view 权限访问。Engineer 可使用看板直接链接；保留原系统隐藏 Sales 导航的规则，不向 Engineer 提供不可达的商机详情跳转。
